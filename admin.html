📝 How to Add Content

  1. Fill out the form on the left
  2. Click "Generate JSON"
  3. Click "Copy JSON"
  4. Open js/data.js
  5. For events: paste inside the EVENTS_DATA array
  6. For skills: paste inside the event's skills array
  7. Save the file and refresh the site!
